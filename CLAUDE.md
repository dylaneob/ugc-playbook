# UGC Playbook

This folder is the repo root for the /ugc skill. For any UGC task (brands, Trybe, scripts, hooks, variations, grading, shoot plans, edits, tracking):
1. Read `CREATOR.md`. If it's empty, fill it in with the creator first.
2. Read `skills/ugc/SKILL.md` and follow it. Paths in it are relative to this folder.
3. Grade scripts with the rules in `rules/ad-copy-grader.md` (or the `ugc-ad-grader` agent if installed) before calling them ready.
4. Never submit, request, post or message for the creator.
